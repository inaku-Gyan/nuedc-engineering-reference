# Catalog

这里是全库的轻量导航层。索引只保存足以帮助定位的信息，不复制资料正文。

## 分类入口

- [硬件资料](hardware.md)：芯片、模块、传感器、电源、仪器、开发板等。
- [软件资料](software.md)：IDE、编译器、SDK、库、调试器软件和工程工具等。
- [知识主题](knowledge.md)：速查、设计方法、故障排查和工作流。
- [外部链接](external-links.md)：尚未归档原件或不适合归档的权威资料入口。

## 推荐检索流程

1. 已知型号：搜索型号或别名，再进入 `library/` 中的资料包。
2. 已知问题：从 `knowledge.md` 的主题入口开始。
3. 只知道类别：从 `hardware.md` 或 `software.md` 逐层缩小范围。
4. 找不到本地资料：检查 `external-links.md`，最后再进行外部检索。

随着资料增加，分类索引应只列常用入口和一行说明。完整清单可由各资料包的
`meta.yaml` 自动生成，避免手工维护多个重复目录。
