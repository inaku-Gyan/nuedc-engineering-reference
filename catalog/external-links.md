# External Links

这里收录未归档原件或不适合归档的权威资料入口。优先保存稳定的官方产品页、
文档页或版本化永久链接，避免只保存搜索结果页。

## 条目格式

```markdown
### 标题

- URL:
- 提供方:
- 文档编号/版本:
- 适用对象:
- 最后核验: YYYY-MM-DD
- 本地资料包: `library/...`（如有）
- 备注:
```

链接达到三个以上时再按硬件、软件、标准、竞赛等主题拆分文件；不要让本文件
变成未经筛选的书签堆。
