# Knowledge

这里保存从一个或多个来源提炼出的工程知识。它不是原件的替代品，而是面向任务
的快速入口。

一篇文章应尽量只解决一个问题。例如：

- `quick-reference/stm32-timer-frequency.md`
- `design-guides/adc-front-end-selection.md`
- `troubleshooting/can-bus-no-ack.md`
- `workflows/oscilloscope-bode-measurement.md`

优先写已在项目中用过、验证过或重复查询过的内容。使用
`templates/knowledge-note.md` 创建文章，并为关键结论提供可回溯来源。
