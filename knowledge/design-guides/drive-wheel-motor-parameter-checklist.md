# 驱动轮电机参数清单与换算

> **结论：** 驱动轮不能只看“电压、转速和减速比”。上电前至少要确认准确
> 版本、额定电压、额定/启动或堵转电流、接线、编码器电气接口以及驱动器电流
> 边界；要完成机械选型和闭环控制，还必须知道轮胎有效直径、输出轴额定转速与
> 转矩、每输出轴一圈编码器计数。缺少其中任一关键量时，应保留为待测参数，
> 不得借用同外形电机的数据。

## 适用场景

- 解决问题：采购、接线、驱动器匹配、底盘速度/牵引力估算和编码器闭环配置。
- 主要对象：带 AB 相增量编码器的有刷直流减速电机和驱动轮。
- 项目实例：12 V、约 1:34 MG370（GMR）与 AT8236 双路驱动板、
  MSPM0G3507 LQFP-64。
- 未覆盖：无刷电机的相线/霍尔换相、FOC 参数，步进电机相电流，以及舵轮的
  转向执行器参数。

## 参数优先级

| 优先级 | 使用时点 | 必须知道的内容 | 缺失时的处理 |
| --- | --- | --- | --- |
| P0 | 首次上电前 | 准确型号/版本、电机类型、电压范围、堵转或启动电流、功率线与编码器线序、编码器供电和输出电平、驱动器连续/峰值电流 | 不接 MCU 或满压电源，先索取资料并受控测量 |
| P1 | 机械选型和闭环前 | 输出轴空载/额定转速、额定转矩、减速比、有效轮径、每输出轴一圈计数、轴和安装尺寸、转向极性 | 不能确定最高速度、牵引力、里程比例或控制器量程 |
| P2 | 整车调试前 | 启动电流和时间、负载工作点、PWM 死区、左右轮差异、温升、回差、轮胎打滑、母线下陷/回灌过冲 | 低占空比、低加速度运行，逐项实测后再开放性能 |

P0 是安全边界，P1 决定系统能否算对，P2 决定实车能否稳定且可重复。销售页只给
“12 V、300 RPM”不足以完成任何一层的确认。

## 电机电气参数

| 参数 | 用途和注意事项 |
| --- | --- |
| 电机类型 | 确认有刷直流、无刷或其他类型；决定驱动拓扑和控制方法 |
| 标称/允许工作电压 | 与电池满充、欠压和驱动器压降一起核对，不能只看电池标称值 |
| 空载电流 | 用于检查装配、齿轮箱和左右轮异常；不能作为驱动器选型电流 |
| 额定电流 | 驱动器、线缆、连接器和散热的连续工作基准 |
| 启动/堵转电流 | 电机静止时反电动势为零，启动电流可能接近堵转电流；用于峰值能力、限流和电源瞬态设计 |
| 绕组电阻/电感 | 可交叉核对堵转电流、估算电流上升速度和分析 PWM 电流纹波 |
| 允许工作制和温升 | 确认能否连续运行、允许峰值持续时间、过温条件和冷却方式 |
| 极性和转向 | 记录施加正向电压时输出轴方向，后续与编码器正方向统一 |

堵转转矩和堵转电流只用于边界设计。除非厂商给出测试方法和允许时间，否则不能把
堵转当成常规台架测试点，也不能依赖驱动芯片的过流保护长期兜底。

## 减速箱、输出轴和车轮参数

| 参数 | 用途和注意事项 |
| --- | --- |
| 实际减速比 | 连接电机轴与输出轴转速/转矩，也用于换算电机轴编码器计数 |
| 输出轴空载/额定转速 | 空载转速用于估计上限，额定转速更接近可持续负载工作点 |
| 额定转矩 | 用于正常牵引力和爬坡设计；不要用堵转转矩代替连续转矩 |
| 峰值/堵转转矩 | 只用于短时机械强度、打滑和故障边界检查 |
| 齿轮箱效率、回差 | 效率影响可用轮上转矩，回差影响低速换向和里程计 |
| 输出轴尺寸和形式 | 轴径、D 形/键槽、伸出长度、螺纹和允许公差决定轮毂能否可靠固定 |
| 安装尺寸和质量 | 安装孔、外形、离地间隙和质量决定底盘布置 |
| 允许径向/轴向载荷 | 车轮直接装在减速箱轴上时尤其重要；资料缺失时不应默认能承受冲击载荷 |
| 轮胎有效直径 | 应测量装车、承载后的滚动直径，不只采用轮胎标称外径 |
| 胎面与地面附着 | 材料、宽度、花纹和地面决定打滑上限；编码器无法观测轮胎相对地面的滑移 |
| 轮/轮毂惯量和同心度 | 影响启动电流、控制响应、振动和左右轮一致性 |

以下为**推导公式**。设有效轮径为 `D_m`（m）、输出轴转速为 `n_rpm`
（r/min）、单轮输出转矩为 `T_wheel_Nm`（N·m）：

```text
理论线速度 v_mps = π × D_m × n_rpm / 60
单轮切向力 F_wheel_N = 2 × T_wheel_Nm / D_m
```

若有多个驱动轮，总牵引力是各轮切向力之和，但还受驱动轮法向载荷和轮地附着
限制。需求侧至少应估算整车质量、目标加速度、最大坡度、滚阻、驱动轮数量和
载荷分配：

```text
所需牵引力约为 F_req = m × a + m × g × sin(坡度角) + F_roll
```

这些公式用于初步选型；齿轮效率、轮胎变形和打滑要通过实车测量修正。

## 编码器参数

| 参数 | 用途和常见误区 |
| --- | --- |
| 编码器类型和通道 | 确认 AB 正交、单通道或是否有 Z/index；AB 相才能直接判方向 |
| PPR/CPR 的定义 | 必须确认供应商说的是每相周期、全部边沿还是已经换算后的计数 |
| 安装轴位置 | 确认编码器在电机轴还是减速箱输出轴；否则会把减速比重复乘入或漏掉 |
| 解码倍率 | 软件采用 1×、2×还是 4×；必须与“每圈计数”常量定义一致 |
| 供电范围和电流 | 确认能否用 3.3 V，不能因插头相同就直接供 5 V |
| 输出类型和电平 | 推挽、开漏/开集、差分；确认高低电平、上拉需求和 MCU 输入兼容性 |
| 最大输出频率 | 必须覆盖最高转速下的边沿率，并为 MCU/QEI 留出余量 |
| A/B 相位和正方向 | 记录电机正转时 A、B 的超前关系，使速度和里程符号一致 |
| 接口线序 | VCC、GND、A、B 与两根电机线逐针确认，同时记录插头观察方向 |
| 抗干扰条件 | 长线、电机刷火和大电流回路下需要检查滤波、屏蔽、共地和边沿质量 |

建议在固件和标定记录中直接保存“每输出轴一圈计数”
`C_out_rev`，避免在各处重复解释 PPR。若供应商给出的是电机轴每相周期数
`PPR_motor`，减速比为 `G`，解码倍率为 `k`，则有以下**条件推导**：

```text
C_out_rev = PPR_motor × G × k
每计数距离 d_m_per_count = π × D_m / C_out_rev
最高计数率 f_count_hz = n_rpm / 60 × C_out_rev
```

若供应商给出的已经是输出轴 CPR 或四倍频计数，不能再次乘减速比或 `k`。
最可靠的实物标定方法是让输出轴缓慢转过多圈，统计总计数后取平均。

## 驱动器、电源和 MCU 匹配

1. 驱动器 VM 范围应覆盖电池从满充到低电量的实际范围，以及制动回灌过冲。
2. 驱动器推荐连续电流应覆盖电机负载工作电流；推荐峰值电流应覆盖经确认的
   启动瞬态。绝对最大值不是工作额定值。
3. 如果堵转电流超出驱动器峰值边界，必须有可信的硬件限流、防堵转时间上限和
   安全停机状态；未知原理图的模块不能假定已经配置合适限流。
4. 电源、保险丝、连接器、线缆、PCB 铜箔和散热均按单/双电机最坏同时启动
   校核，而不是只按空载电流。
5. 明确 PWM 频率、衰减/制动方式、换向流程、最小启动占空比和加减速斜坡。
   急反转和硬制动会同时增加电流、机械冲击和母线回灌。
6. 编码器输入既要满足电压边界，也要满足定时器引脚映射和最高计数率。

对本项目 MCU，MSPM0G3507 普通 GPIO 输入上限为 `VDD+0.3 V`，只有 PA0、
PA1 是 5 V 容限 ODIO。MSPM0G3507 仅 TIMG8 提供一路硬件 QEI；两路驱动轮
编码器并用时，另一路需要软件解码或外部计数方案，并按最高计数率评估中断负载。

| 输出轴/安装/载荷 | **未知** | 缺轴径、安装孔、径向载荷、回差等 |
| 热与寿命参数 | **未知** | 缺工作制、允许温升、峰值持续时间和寿命 |

该电机与当前 AT8236 驱动板的关键结论：

- 1.1 A 额定电流低于 AT8236 推荐连续 3 A，正常负载电流有余量；
- 6.2 A 堵转电流高于推荐峰值 4.5 A，并略高于绝对峰值 ±6 A；
- 因此该组合**不具备堵转安全余量**，需软启动、防堵转、受控限流和最坏工况
  实测，不能把芯片 6–10 A 的过流阈值当作精确限流；
- 12 V 已处于亚博 YB-MTNO3-V1.0 模块公开输入范围 5–12 V 的上限，需在
  板端测量双电机启动时的下陷和制动时的过冲。

## 建议补参流程

1. 记录电机、编码器、减速箱、驱动板和车轮的完整型号、卖家规格、板号与批次。
2. 断电用导通档确认电机线和编码器线，标注插头观察方向；测量轴、安装和轮径。
3. 编码器先限流供电并用示波器确认 A/B 输出电平、输出类型、相位和噪声；优先
   从已确认支持的 3.3 V 开始。
4. 手转输出轴至少数圈，得到 `C_out_rev`，同时记录正方向。
5. 电机先限流、低占空比启动，确认方向、空载电流、空载转速和最小启动占空比。
6. 装车后测量承载有效轮径、左右轮差异、典型/最坏负载电流、启动时间、驱动板
   温升、VM 下陷和回灌过冲；逐步提高速度和加速度。
7. 将最终值固化为带单位和来源的底盘标定参数，并记录测量条件和日期。

不要直接施加满压做堵转试验。若必须确定堵转边界，应采用限流电源、电流探头、
很短的受控测试时间和明确的过温/失控切断措施。

## 证据边界

- **官方资料：** AT8236 的推荐/绝对电流、PWM、保护和控制；MSPM0G3507 的
  GPIO 电压与定时器资源。
- **二手版本证据：** 当前 MG370 的数值与六针线序，来源无法追溯到电机厂商，
  所有关键值均需实物复核。
- **推导结论：** 速度、牵引力、编码器计数和单位换算公式；使用前提已在对应
  小节给出。
- **待验证：** 当前电机的 PPR、电气输出、机械尺寸、温升，以及驱动模块的
  实际限流、散热、连接器载流和双电机瞬态。
