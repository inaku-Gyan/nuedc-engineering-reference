# 天猛星开发板硬件配置注意事项

> **结论：** 使用这块板时优先确认 VCORE 禁止外部供电/带载、参考电压选择、
> BSL/串口下载连接和排针电源域；完整引脚复用仍以规格书第 2 页和 MCU 数据表为准。

## 适用范围

- 对象：立创·天猛星 MSPM0G3507 开发板
- 型号：LCKFB-TMX-MSPM0G3507 / C42378531
- 原理图日期：2024-11-14
- 硬件版本：原理图未标明；使用前核对实物

## 主控、时钟和模拟地

- 主控为 64 引脚 MSPM0G3507。
- 高速晶振 X1 为 40 MHz，连接 PA5/HFXIN 和 PA6/HFXOUT。
- 低速晶振 X3 为 32.768 kHz，连接 PA3/LFXIN 和 PA4/LFXOUT。
- 原理图对 PA2/ROSC 标注“精度很重要”。
- 数字地与模拟地采用单点连接。
- 原理图明确警告：VCORE 是稳压内核电源输出，不得向 VCORE 引脚供电，也不得
  施加外部负载。

## USB、电源和参考电压

- Type-C 接口提供 `VBUS_5V`，CC1/CC2 各有 5.1 kΩ 下拉。
- USB 电源入口标有 500 mA 保险丝，并配置浪涌/ESD 保护器件。
- 板载降压电路将 5 V 转为 3.3 V；原理图给出的反馈公式为
  `Vout = 0.6 × (1 + R1/R2)`。
- PA23/VREF+ 有三路参考来源选择：板内 3.3 V 经磁珠后的电压、板载参考电压
  芯片、外部排针参考电压。原理图要求三者只选其一。
- 使用外部排针参考电压时，原理图提示需要补装相邻的两个电容。
- 具体 0 Ω/NC 电阻装配状态可能随批次变化，必须核对实物后再切换参考源。

## 下载、调试和扩展

- 板载 CH340E 用于 USB 转串口，连接主控 UART0，并用于 BSL 串口下载。
- 板上提供 BSL、复位和用户按键，以及独立 SWDIO/SWCLK 调试焊盘。
- 提供 W25Q128 SPI Flash。
- 提供常用 SPI LCD 接口，也标注兼容部分 SPI OLED 屏。
- 两侧双排针引出了电源、模拟、CAN、I2C、UART、SPI、Timer 等复用信号。
  不应根据颜色或相邻位置猜测复用功能，应查规格书第 2 页并用 MCU 数据表复核。
