## I²C 写入格式

SSD1315 的 7 位地址由固定前缀 `011110` 和 `SA0` 组成，因此地址为 `0x3C` 或
`0x3D`。本模组原理图将兼作 `SA0` 的 `D/C#` 接地，故推导地址为 `0x3C`。

从地址后的第一个字节是控制字：

| 控制字 | `Co` | `D/C#` | 后续字节含义 |
| --- | ---: | ---: | --- |
| `0x00` | 0 | 0 | 命令及其参数 |
| `0x40` | 0 | 1 | 写入 GDDRAM 的显示数据 |

`Co = 0` 表示本次传输余下的字节保持同一类型。每写入一个显示数据字节，当前
GDDRAM 列地址自动加一。

## GDDRAM 布局

128 × 64 GDDRAM 分为 8 页，每页覆盖 8 行、包含 128 个列字节。一个字节对应
当前列的 8 个纵向像素：`D0` 是页内最上方像素，`D7` 是最下方像素。因此完整
帧缓冲为 `8 × 128 = 1024 byte`。

页寻址模式下，常用定位序列为：

1. `0xB0 | page` 选择第 0～7 页；
2. `0x00` 设置列地址低 4 位为 0；
3. `0x10` 设置列地址高 4 位为 0；
4. 使用 `0x40` 控制字连续发送该页数据。

## 初始化依据

控制器手册对内部电荷泵应用明确要求：复位和供电稳定后用 `0x8D` 配置电荷泵，
再用 `0xAF` 开启显示；关闭时先发 `0xAE`，再用 `0x8D 0x10` 关闭电荷泵。
四针模组没有引出 `RES#`，因此主控驱动无法执行手册中的外部复位脉冲，首次上电
仍需由实物测试确认供电稳定时间和上电可靠性。

资料包内 SPI 示例的初始化参数如下：

| 功能 | 命令 |
| --- | --- |
| 显示关闭 | `AE` |
| 页寻址模式 | `20 02` |
| 起始列、起始行、起始页 | `00`、`10`、`40`、`B0` |
| 对比度 | `81 FF` |
| SEG 重映射、正常显示、跟随 RAM | `A1`、`A6`、`A4` |
| COM 扫描方向 | `C8` |
| 64 MUX、零偏移 | `A8 3F`、`D3 00` |
| 时钟、预充电、COM 引脚、VCOMH | `D5 80`、`D9 1F`、`DA 12`、`DB 40` |
| 9.0 V 内部电荷泵 | `8D 95` |
| 显示开启 | `AF` |

在软件中先保持 `AE`，清零全部 GDDRAM 后再发送 `AF`，可避免上电时短暂显示
未初始化显存。这是工程策略，不是数据手册强制的命令顺序。

## 总线共享时的工程结论

SSD1315 数据手册没有规定应用层分片大小。当前项目让 OLED 与 PCA9685 共用
400 kbit/s I²C，因此应在每笔数据前重新发送 `0x40` 控制字并限制事务长度；
页面完成前保留脏状态，出错后从页地址重新开始。具体分片上限和刷新频率属于项目
实时性决策，不应当作 SSD1315 器件限制复用到其他系统。
