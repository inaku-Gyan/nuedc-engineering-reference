# 金逸晨 GME12864-49～54 0.96 英寸 OLED 模组

> 128 × 64 被动矩阵 OLED，板载 SSD1315，外部使用四针 I²C 接口。资料包同时保留
> 模组规格书、转接板原理图、SSD1315 Rev 1.0 数据手册及一份 8051 SPI 示例；其中
> SPI 示例不适用于这块只引出四针 I²C 的转接板。

## 快速定位

- 厂商：深圳市金逸晨电子有限公司（GoldenMorning）
- 型号族：`GME12864-49`、`-50`、`-51`、`-52`、`-53`、`-54`
- 显示：0.96 英寸、128 × 64、1/64 duty
- 控制器：SSD1315
- 模组接口：四针 I²C
- 资料包 ID：`hw-display-goldenmorning-gme12864-49-54`

## 四针接口

规格书和原理图给出的连接器顺序一致：

| 针位 | 丝印 | 含义 |
| ---: | --- | --- |
| 1 | GND / VSS | 地 |
| 2 | VDD | 模组电源输入，原理图网络名为 `VDDin` |
| 3 | SCK | I²C 时钟，等同 SCL |
| 4 | SDA | I²C 数据 |

原理图中 SCK、SDA 各有一个 10 kΩ 上拉电阻，均上拉到板载稳压后的 3.3 V
`VDD`，不是外部接口的 `VDDin`。因此外部 `VDDin` 高于 3.3 V 时不会把 I²C
总线直接上拉到同样的电压。SSD1315 的 `D/C#`（I²C 模式下兼作 SA0）被接地，
因此根据控制器手册可**推导**本板的 7 位从地址为 `0x3C`。首次接线时仍应先
扫描总线确认，不要把包含 R/W 位的 `0x78` 当作 7 位地址传给驱动库。

## 供电边界

模组规格书分别列出逻辑电源 `VDD = 3.0 V` 和面板驱动电源 `VCC = 12.0 V`；这是
内部两条电源轨，不应解释为外部四针接口支持 `3～12 V`。转接板原理图显示：

- `VDDin` 经标注为 `XC6206P`、输出标注为 3.3 V 的稳压器给逻辑电路供电；
- SSD1315 使用内部电荷泵，外围有 1 µF、2.2 µF 和 4.7 µF 电容；
- 原理图和现有资料均没有明确给出外部 `VDDin` 的允许范围。

因此在没有实物丝印、商品页或稳压器完整型号佐证前，外部供电电压应视为待确认项；
首次上电使用限流电源。

## 示例代码适用性

随附 `.C`/`.hex` 是面向 8051 的四线 SPI 示例，源码需要 `_CS`、`RES`、`RS`、
`SCL` 和 `SI` 五根控制线。当前四针板只引出 GND、VDD、SCK、SDA，不能直接运行
该示例。源码为 GBK 编码、CRLF 换行，归档时保持原始字节不变；`.hex` 只能作为
随附固件样本，不能替代可审计的源代码移植。
