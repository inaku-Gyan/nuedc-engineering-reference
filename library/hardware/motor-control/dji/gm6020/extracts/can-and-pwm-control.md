# GM6020 CAN 与 PWM 控制速查

> 汇总 GM6020 的 CAN 标识符、数据格式、拨码设置和 PWM 控制条件。

## 适用范围

- 对象：RoboMaster GM6020
- 文档版本：v1.4，2023.10
- CAN 总线：1 Mbit/s，标准数据帧，DLC 8

## ID 与终端电阻

拨码开关第 1–3 位对应 ID 的 Bit0–Bit2，拨至 ON 为 1。`000` 无效，
`001`–`111` 分别对应 ID 1–7。第 4 位拨至 ON 时接入 CAN 终端电阻。

| 电机 ID | 反馈标识符 | 电压控制标识符 | 电流控制标识符 | 数据槽 |
| ---: | ---: | ---: | ---: | --- |
| 1 | `0x205` | `0x1FF` | `0x1FE` | DATA[0:1] |
| 2 | `0x206` | `0x1FF` | `0x1FE` | DATA[2:3] |
| 3 | `0x207` | `0x1FF` | `0x1FE` | DATA[4:5] |
| 4 | `0x208` | `0x1FF` | `0x1FE` | DATA[6:7] |
| 5 | `0x209` | `0x2FF` | `0x2FE` | DATA[0:1] |
| 6 | `0x20A` | `0x2FF` | `0x2FE` | DATA[2:3] |
| 7 | `0x20B` | `0x2FF` | `0x2FE` | DATA[4:5] |

每个给定值均按高 8 位在前、低 8 位在后的两个字节发送：

- 电压给定值：`-25000…25000`；
- 电流给定值：`-16384…16384`，对应 `-3…3 A` 最大转矩电流。

未控制的数据槽应写 0。电流控制要求电机固件不低于 `1.0.11.2`、RoboMaster
Assistant 不低于 2.7，并在参数设置中打开电流环。

## 反馈帧

反馈标识符为 `0x204 + 电机 ID`，发送频率 1 kHz：

| 字节 | 内容 | 单位或范围 |
| --- | --- | --- |
| DATA[0:1] | 机械角度，高字节在前 | 0–8191 |
| DATA[2:3] | 转速，高字节在前 | rpm |
| DATA[4:5] | 实际转矩电流，高字节在前 | 驱动器反馈值 |
| DATA[6] | 电机温度 | ℃ |
| DATA[7] | 保留 | — |

机械角度是 13 位单圈值。做多圈位置控制时，控制器需根据相邻采样跨越
0/8191 的方向自行累计圈数。

## PWM 控制

- 输入频率：50 Hz；
- 默认脉宽行程：1000–2000 μs；
- 支持速度模式和位置模式，默认为位置模式；
- CAN 与 PWM 同时输入时，CAN 优先。

行程校准：

1. PWM 设置到 1900–2100 μs 后给电机上电；
2. 指示灯绿灯常亮后，在 3 s 内切换到 900–1100 μs；
3. 绿灯慢闪表示成功，橙灯快闪表示失败。
