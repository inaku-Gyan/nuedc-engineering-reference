# 飞特 FT6335M 舵机

> 7.4 V、35 kg·cm 级的 360°磁编码数字舵机，采用 PWM 脉宽位置控制。当前资料包
> 适合核对供电、扭矩/电流、控制脉宽、接口和保护条件。

## 快速定位

- 型号：FT6335M
- 厂商：深圳飞特模型有限公司（FEETECH）
- 资料包 ID：`hw-motor-control-feetech-ft6335m`
- 产品：钢齿轮、铝中壳、铁芯电机、12 位磁编码、360°行程舵机
- 本地规格书页面标注：Edition A/1，2020-10-28

## 关键参数

| 参数 | 6 V | 7.4 V |
| --- | ---: | ---: |
| 空载速度 | 0.238 s/60° | 0.192 s/60° |
| 空载电流 | 150 mA | 180 mA |
| 堵转扭矩 | 28.8 kg·cm | 35.5 kg·cm |
| 堵转电流 | 3.2 A | 3.9 A |
| 额定扭矩 | 9.5 kg·cm | 11.8 kg·cm |
| 额定电流 | 1.0 A | 1.2 A |

其他关键条件：

- 可输入电压：4–8.4 V；
- 工作温度：−20–60 °C，保存温度：−30–80 °C；
- 机械尺寸：55 × 20 × 43 mm，重量 67 ± 1 g；
- 防护等级：IP54；
- PWM 周期 20 ms，脉宽 500–2500 μs，中位 1500 μs；
- 堵转保护标称 4 s，温度超过 70 °C 时停止输出。

## 使用注意

- 本地文件封面和正文均标为 A/1，但第 2 页变更记录列出了
  `A/2 / 2021-08-04 / 更新控制方向`。因此旋转方向等版本敏感信息在装机前应
  通过实物验证，并与飞特最新官方资料核对。
- 3.9 A 是 7.4 V 堵转电流，不是正常连续工作电流；电源和线缆应考虑启动、
  瞬态和多舵机同时动作。
- 资料描述的是 500–2500 μs 对应 360°的脉宽位置控制，不应仅凭“360°”字样
  当作无限连续旋转舵机使用。
