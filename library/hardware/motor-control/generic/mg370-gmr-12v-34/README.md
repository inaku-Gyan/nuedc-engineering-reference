# MG370 12 V、约 1:34 GMR 编码器减速电机

> 来源未明的随货/商品资料所描述的一种 MG370 版本。可用于限定本批候选电机的
> 电压、电流、减速比、六针线序和编码器候选参数，但不能推广到所有 MG370。
> 编码器图片虽标称 500 PPR，仍未定义 PPR 口径和安装轴位置，装机前必须实测。

## 编码器候选参数

来源未明的编码器参数图给出：

- GMR 编码器线数：500 PPR；
- 类型：巨磁阻效应；
- 供电范围：3.3–5 V；
- 输出带上拉，默认上拉到编码器供电 VCC。

图片没有说明 500 PPR 是单相周期数、全部边沿计数还是输出轴换算值，也没有说明
编码器安装在电机轴还是减速箱输出轴。因此固件中不能直接把 `500` 当作每输出轴
一圈计数。

若后续实测确认 500 PPR 表示电机轴单相周期数，且采用 AB 相四倍频，则可作以下
**条件推导**：

```text
每输出轴一圈计数 = 500 × 34.014 × 4 = 68028
300 RPM 输出轴转速下的计数率 = 300 / 60 × 68028 ≈ 340140 count/s
```

该条件下应使用硬件定时器编码器模式，不应把全部边沿交给 GPIO 中断。

## 使用注意

- 资料无法追溯厂商、商品页或公开来源，所有数值都需要与实物铭牌和受控测量复核。
- 6.2 A 堵转电流超过 AT8236 的推荐 4.5 A 峰值，并略高于 ±6 A 绝对峰值，
  这一组合不具备堵转安全余量。
- 编码器参数图允许 3.3–5 V 供电并称输出上拉至 VCC；搭配 3.3 V MCU 时优先
  以 3.3 V 供电，首次接入前仍应用示波器确认 A/B 电平、相位和最高频率。
- GMR 编码器版本和霍尔版本可能使用不同线序，不能只凭电机外形判断。
