## 使用注意

- 资料无法追溯厂商、商品页或公开来源，所有数值都需要与实物铭牌和受控测量复核。
- 6.2 A 堵转电流超过 AT8236 的推荐 4.5 A 峰值，并略高于 ±6 A 绝对峰值，
  这一组合不具备堵转安全余量。
- 编码器优先以 3.3 V 供电；没有确认 A/B 电平前，禁止接入 3.3 V MCU。
- GMR 编码器版本和霍尔版本可能使用不同线序，不能只凭电机外形判断。
