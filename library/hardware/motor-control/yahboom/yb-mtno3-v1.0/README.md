# 亚博 YB-MTNO3-V1.0 双路 AT8236 电机驱动模块

> 两路有刷直流电机与两组编码器接口的成品板。当前资料包用于核对板上端子、
> 双 PWM 控制和供电范围；芯片电流极限仍以 AT8236 数据手册为控制来源。

## 快速定位

- 板卡丝印：`YB-MTNO3-V1.0`
- 厂商：亚博智能（Yahboom）
- 资料包 ID：`hw-motor-control-yahboom-yb-mtno3-v1-0`
- 驱动芯片：2 × AT8236
- 公开产品族：2-Channel Motor Driver Module

## 关键参数与接口

亚博官方仓库当前说明：

- 模块电源输入 5–12 V，带反接保护；
- 可输出 5 V/3 A 或 3.3 V/500 mA 给主控/编码器；
- 单路宣称额定 3.6 A、峰值 6 A；
- 支持两路带编码器电机、VM 检测和多板级联。

上述电流是板级宣传值。AT8236 芯片 V1.1 的推荐工作条件只有 3 A 连续、
4.5 A 峰值，绝对峰值 ±6 A；工程设计不得用模块宣传值放宽芯片边界。

每路使用两个逻辑输入：

| IN1 | IN2 | H 桥状态 |
| ---: | ---: | --- |
| 0 | 0 | 滑行 |
| PWM | 0 | 一个方向调速 |
| 0 | PWM | 反方向调速 |
| 1 | 1 | 制动 |

换向前应先双低并等待至少一个 PWM 周期，不要从正向高占空比直接切到反向。

## 使用注意

- inbox 三张图没有保留可追溯 URL，不能证明其再分发许可；这里只把它们作为
  用户持有板卡的版本证据，不升级为一手控制资料。
- 12 V 是模块公开输入范围上限。制动回灌、线缆电感和双电机启动可能造成 VM
  过冲或下陷，必须在板端用示波器核验。
- 编码器电源优先选择 3.3 V；未确认 A/B 输出电平前不要接入 3.3 V MCU。
- PH2.0-6P 外形相同不代表不同电机的线序相同，装机前逐针导通确认。
