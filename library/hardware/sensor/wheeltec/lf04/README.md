# WHEELTEC LF04 四路红外巡线模块

> 四组 940 nm 反射式光电传感器、四个独立阈值电位器和一颗 LM339 四路比较器组成
> 的开关量巡线模块。每路只输出高/低电平，不提供连续反射强度。

## 快速定位

- 型号：`LF04`
- 厂商：WHEELTEC（轮趣科技）
- 传感器：4 × XGBRIGHT `XG-ITR20001/T24`
- 比较器：`LM339PWR`
- 接口：VCC、GND、O1～O4
- 资料包 ID：`hw-sensor-wheeltec-lf04`

## 通道与接口

使用手册给出的通道映射为：

| 传感器 | 阈值电位器 | 输出 |
| --- | --- | --- |
| U5 | U1 | O1 |
| U6 | U2 | O2 |
| U7 | U3 | O3 |
| U8 | U4 | O4 |

原理图把同一组输出写作 `OUT1`～`OUT4`，并按连接器编号给出：

| 针位 | 信号 |
| ---: | --- |
| 1 | OUT1 / O1 |
| 2 | OUT2 / O2 |
| 3 | OUT3 / O3 |
| 4 | OUT4 / O4 |
| 5 | VCC |
| 6 | GND |

针位表依据原理图连接器编号；接线前仍应结合实物丝印确认观察方向。

## 检测逻辑与调节

手册说明，在白底黑线场景中：

- 白底反射足够：对应输出为高电平，指示 LED 熄灭；
- 黑线吸光或无有效反射：对应输出为低电平，指示 LED 点亮；
- 电位器顺时针增加识别距离，逆时针降低识别距离；
- 建议先以约 3 cm 探头高度调到 LED 刚好翻转，再反复在黑线、白底之间复核。

手册建议用四位真值表直接处理巡线状态，并指出四个离散检测点之间存在死区。其示例
把 `0000` 视为十字路口、`1001` 视为直行、`1111` 视为丢线；这些状态依赖传感器
左右安装顺序和上述有效电平定义，移植时不能照抄而不验证。

## 电气边界

- 原理图中 LM339 四路输出各由 10 kΩ 电阻上拉到 `VCC`，因此输出高电平接近
  模块供电电压，而不是固定 3.3 V。
- 手册把输出称为 TTL 电平，但没有给出模块允许的 VCC 范围、输入电流或输出电平
  保证值。接 3.3 V MCU 前应确认模块实际供电和 GPIO 是否 5 V 容忍。
- 四个发射管各串联 1 kΩ 电阻；每路比较阈值由 1 kΩ 电位器和 10 kΩ 电阻网络
  设置。原理图注释称阈值调节范围约为 0～1 V。
- XG-ITR20001/T24 规格书给出峰值波长 940 nm；该数值是传感器器件参数，不等于
  整块 LF04 的有效检测距离保证。

环境光、探头高度、赛道平整度和表面反射率都会改变翻转点。手册明确要求避开阳光
直射，并在实际场地逐通道调节。
