# Ingestion Guide

## 1. 判断放在哪里

- 单一产品、器件、工具、标准或赛题的资料：`library/`
- 跨多个来源形成的结论或实践方法：`knowledge/`
- 只有在线入口且不能归档：`catalog/external-links.md`
- 尚未判断清楚：暂存 `inbox/`

## 2. 建立资料包

根据 `catalog/hardware.md` 或 `catalog/software.md` 选择主题路径。复制：

- `templates/reference-readme.md` 为资料包 `README.md`
- `templates/meta.yaml` 为资料包 `meta.yaml`

删除不适用的模板字段，不要保留无意义的占位内容。

## 3. 归档原件

- 优先使用厂商、标准组织或 NUEDC 官方来源。
- 文件名包含对象、文档类型和版本。
- 在 `meta.yaml` 中记录来源 URL、获取日期、文档编号、版本和 SHA-256。
- 公开可访问的官方工程资料在再分发许可未明确时可以归档，但必须标记
  `redistribution: unknown`。
- 付费、需登录、保密、泄露或明确限制传播的资料不得归档，只保存允许公开的
  链接和元数据。
- 扫描件或 OCR 文件要区分原始文件与衍生文件，不能覆盖原件。

## 4. 写最小摘要

资料包 `README.md` 应足以回答：

- 这是什么，适用于哪些型号或版本？
- 在电赛项目中通常何时需要它？
- 最重要的入口和限制条件是什么？
- 当前摘要覆盖了什么，明确没覆盖什么？
- 要核验细节应该打开哪份原件的哪一章？

摘要不应变成原件的缩写版。

## 5. 按需制作摘录

使用 `templates/extract.md`。每个摘录围绕一个清晰问题，保留：

- 来源文件和文档版本；
- 页码、章节或表号；
- 适用型号、工作条件和例外；
- 提取日期；
- 必要时记录 OCR 或人工整理造成的不确定性。

表格应只保留当前主题需要的列。大量重复寄存器表、封装表和订购信息不要无目的
复制。

## 6. 更新索引并检查

- 在相应 `catalog/*.md` 增加真正有导航价值的入口。
- 检查资料包 ID 是否唯一、链接是否有效、版本是否一致。
- 确认没有密钥、个人数据、受限资料或无授权的大文件。
- 原件变化后复核已有摘要和摘录。
